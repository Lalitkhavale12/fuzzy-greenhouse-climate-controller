## Plant physics fidelity

| Option | Description | Selected |
|--------|-------------|----------|
| Decoupled ODEs | Each state driven by a first-order ODE; humidity sees only actuator effects, temp only temp actuators. Simplest, but RH won't drop when temp rises. | |
| Coupled energy+mass | Energy balance + moisture balance cross-linked — heating inherently lowers RH, fogging mildly cools. Realistic without being heavy. | ✓ |
| Full physics | Psychrometrics, sun radiation, wall conduction. Overkill for a benchmark, slows GA runs. | |

**User's choice:** Coupled energy+mass
**Notes:** Explicitly contrasted against full psychrometrics as overkill for a benchmark study.

| Option | Description | Selected |
|--------|-------------|----------|

| Planner's pick | Model constants just reasonable numbers. | |

**User's choice:** Literature defaults

**User's choice:** Absolute humidity (g/kg)

## Actuator effects

| Option | Description | Selected |
|--------|-------------|----------|
| Full coupling | Heat adds energy; fogger adds moisture AND cools; fan extracts heat; vent exchanges air (both states toward ambient). | ✓ |
| Clean 1:1 mapping | Each actuator on one state only — simple but unrealistic. | |
| Coupling but simplified vent | Coupling for heat/fog, vent approximated via constant leak. | |

**User's choice:** Full coupling

| Option | Description | Selected |
|--------|-------------|----------|
| Proportional rate | Duty % maps to a proportional rate (heat rate ∝ duty). Smooth for PID/fuzzy. | ✓ |
| Real relays + saturation | Min-turn-on, saturation — real valve/relay nonlinearity. | |

**User's choice:** Proportional rate

| Option | Description | Selected |
|--------|-------------|----------|
| Named params in a dict | Coefficients for each actuator×state in model config, reusable/tunable later. | ✓ |
| Inline constants | Hard-coded inside greenhouse_model.py — less transparent. | |

**User's choice:** Named params in a dict

| Option | Description | Selected |
|--------|-------------|----------|
| All four always active | Every actuator affects state in the same simulation. | |
| Only spec'd inputs | Wire the four spec'd inputs into the coupling matrix, no extras (no shading/CO2). | ✓ |

**User's choice:** Only spec'd inputs

## Weather profile shape

| Option | Description | Selected |
|--------|-------------|----------|
| Pure sine cycle | Smooth 24h, predictable, easy to debug — no transients. | |
| Day/night piecewise | Plateaus with smooth transitions. | |
| Noisy realistic cycle | Sine backbone + mild gaussian noise (clouds/wind). Controllers must reject disturbances. | ✓ |

**User's choice:** Noisy realistic cycle
**Notes:** Chosen because it is closer to the "beat the baselines" benchmark.

| Option | Description | Selected |
|--------|-------------|----------|
| CSV rows + interpolation | Store time,temp,humidity rows; model interpolates at any dt. Literal to "consumes weather_profile.csv". | ✓ |
| Parametric in CSV | CSV stores coefficients; code regenerates the curve. | |

**User's choice:** CSV rows + interpolation

| Option | Description | Selected |
|--------|-------------|----------|
| Opposing temp/RH | Night cool & humid, midday warm & drier; RH opposite to T. | ✓ |
| Correlated hot+humid | Both creep together — more punishing. | |

**User's choice:** Opposing temp/RH

| Option | Description | Selected |
|--------|-------------|----------|
| One seeded default profile | 24h × 15min rows generated by a src/ script, deterministic. | |
| Configurable generator | Amplitude/duration/noise-seed configurable for later phases. | ✓ |

**User's choice:** Configurable generator

## Simulation framing

| Option | Description | Selected |
|--------|-------------|----------|
| Fixed-step Euler | dt=60s, fast, cheap for GA fitness runs. | ✓ |
| RK4 fixed-step | More accurate, slightly slower; overhead × GA generations. | |
| Adaptive integrator | scipy solve_ivp; adds scipy dependency, less deterministic. | |

**User's choice:** Fixed-step Euler

| Option | Description | Selected |
|--------|-------------|----------|
| 24h / dt 60s default | 1440 steps; horizon/step exposed as params. | ✓ |
| Separate GA/proof horizons | Shorter horizon for GA fitness, full 24h for proof runs. | |

**User's choice:** 24h / dt 60s default

| Option | Description | Selected |
|--------|-------------|----------|
| Pure step function | Stateless `step(dt, actuators, weather) -> (temp, humidity)`; sim state in caller. | ✓ |
| Stateful class | Greenhouse class mutating self; re-instantiate per GA run. | |

**User's choice:** Pure step function

| Option | Description | Selected |
|--------|-------------|----------|
| Return g/kg + helper | step returns temp + g/kg; `to_rh()` helper for %RH. | |
| Return both units | step returns absolute and relative humidity; no conversion by callers. | ✓ |

**User's choice:** Return both units
